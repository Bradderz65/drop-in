# Drop In

Android local-network drop-in app with camera, microphone, LAN device discovery, and WebRTC-based audio/video sessions.

## Features

- Responsive Jetpack Compose interface
- Camera and microphone permission handling
- Local device discovery via Android NSD
- Local signaling over WebSocket
- WebRTC peer-to-peer audio/video calls

## Build

Use Android Studio or a local Android SDK with Gradle to build:

```bash
./gradlew assembleDebug
```
